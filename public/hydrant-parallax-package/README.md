# Hydrant Parallax Package

Files:
- `all-fire-services-hydrant-parallax.webp` — 1920×1440 WebP, prepared with extra vertical room for parallax movement.
- `parallax-demo.html` — responsive, dependency-free demo.

Usage:
1. Keep both files in the same folder.
2. Open `parallax-demo.html`.
3. Replace the sample heading and paragraph with your website content.

Recommended settings:
- Section height: 70–90vh
- Image height: 124–130%
- Movement range: 80–140px
- Mobile object position: approximately 57% center
- Always honor `prefers-reduced-motion`
