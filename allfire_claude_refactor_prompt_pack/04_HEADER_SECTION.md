# Header Section Prompt

Refactor the global header into a simple, fast, accessible navigation bar.

## Required content

- Latest All Fire Services logo
- Home
- Our Story
- Our Clients
- Services
- Contact
- Phone number when it fits without crowding
- Primary `Get a Quote` button

## Desktop layout

Use a clean horizontal header:

- Logo left
- Navigation centred or right-aligned
- Phone as a quiet utility link
- Get a Quote as the strongest action

Keep the header height compact but comfortable, around 72–88px.

## Mobile layout

- Logo left
- One clear menu button right
- Accessible slide-down or side panel navigation
- Quote and call actions easy to reach
- No nested mega-menu

## Behaviour

- Sticky is acceptable only if it does not cover content or feel heavy.
- If sticky, add a subtle border or background change after scroll.
- Avoid glass blur and large shadows.
- Keep transitions subtle.
- Menu must work with keyboard, Escape, focus trapping, and screen readers.

## Remove

- Large mega-menu panels
- Duplicate service navigation blocks
- Decorative hover animations
- “Welcome” strapline
- Unnecessary social links in the main header
